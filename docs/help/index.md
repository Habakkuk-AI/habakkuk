Something not working? Run `hk doctor` first. It checks the config, keys, storage, channels and MCP servers, and tells you what's wrong by name. `hk status` and `hk logs -f` show what a running `serve` is doing.

<!-- cards -->
- [FAQ](faq.md): which models, what it costs, where data lives, Windows, privacy and more.
- [Troubleshooting](troubleshooting.md): common errors by symptom, with the message you will see and the fix.

Still stuck? Open an issue on [GitHub](https://github.com/habakkuk-ai/habakkuk/issues) with the output of `hk doctor` and `hk version`. Report security problems privately, as described in [SECURITY.md](../../SECURITY.md).
