Come here when you know what you're looking for and want the full list. Each reference page puts everything on its subject in one place. The guides in the other sections explain when and why you'd use each piece.

<!-- cards -->
- [CLI](cli.md): every `habakkuk` command with its flags, plus every command you can send in a chat.
- [Configuration](configuration.md): each section of `config.yaml`, with the settings for providers, agents and channels.
- [HTTP API](api.md): the JSON API under `/api/`, which the dashboard itself is built on.
- [Architecture](architecture.md): how Habakkuk is put together, covering layers, durable jobs, storage, models, permissions, channels, memory and operations.

For configuration, the source of truth is `internal/config`. Every setting is documented there, beside its field.
