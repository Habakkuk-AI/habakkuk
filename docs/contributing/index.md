This section is for you if you want to work on Habakkuk itself. Habakkuk is one Go module, `github.com/habakkuk-ai/habakkuk`, licensed under the Apache License 2.0. Start with the repository's [contributing guide](../../CONTRIBUTING.md). It covers the development setup, the `make` targets, how to add a channel or a provider, and the pull request checklist.

<!-- cards -->
- [Codebase map](codebase.md): what each package does, where to start reading, and the path a message takes.
- [Brand](brand.md): which logo file to use, the colours, and what the mark means.
- [Roadmap](roadmap.md): the release phases and the known gaps.

## Writing docs

The docs live in `docs/`, with one folder for each section. They're published at [habakkuk.ai/docs](https://habakkuk.ai/docs). Describe what the code does today. If you're not sure, check the code. CONTRIBUTING.md lists the page conventions for frontmatter, callouts, tabs and card lists.
