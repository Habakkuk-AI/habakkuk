# Proofread

Proofreading fixes mistakes. It does not rewrite. Leave the author's style, word choices and structure alone unless something is wrong.

## Find out

- Which variety of the language: British or American English, for example. If the text is consistent, follow it.
- Any house style: how dates, numbers, titles and headings are written.
- Whether the user wants only errors fixed, or suggestions on clarity too. Default to errors only.

## Check, in passes

1. **Spelling and typos**, including real words in the wrong place: form and from, their and there.
2. **Grammar**: subject and verb agreement, tense that drifts, sentences without a verb, pronouns with no clear owner.
3. **Punctuation**: missing full stops, comma splices, apostrophes, quotation marks that open and never close.
4. **Consistency**: one spelling of each name, one date format, one way of writing numbers, the same capitals in headings.
5. **Facts on the page**: totals that do not add up, a date that falls on the wrong weekday, a name spelled two ways, a link that does not match its label. Flag these. Do not fix them by guessing.
6. **Layout**: doubled spaces, numbering that skips, a heading left alone at the foot of a section.

## Report

For a short text, return the corrected version followed by a list of changes: the original, the fix, and the reason in a few words.

For a long text, return the list only, grouped by section, so the author can apply them.

Mark each item as one of:

- **Error**: wrong by any standard. Fix it.
- **Query**: possibly wrong, or unclear. Ask the author.
- **Suggestion**: a matter of style. Only if the user asked for these.

## Do not

- Change meaning, tone or emphasis.
- Replace the author's words with ones you prefer.
- Correct quoted text. Flag it.
- Rewrite a sentence that is merely not how you would say it.

Finish with a count: how many errors, how many queries.
