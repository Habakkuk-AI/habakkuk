# Summarize

## Read all of it

Read the whole source before writing. For a file, use the tool that reads documents. For a link, fetch the page. If it is too long for one pass, go section by section and keep notes, then write from the notes. Say so if you could only read part.

## Decide the shape

Ask only if you cannot tell from the request:

- **Who is it for**, and what will they do with it?
- **How long**: one line, a paragraph, or a page. Default to a short paragraph plus up to five points.

## Write

1. First sentence: the single most important thing the source says.
2. Then the main points, in order of importance, not in the order they appear.
3. Then what the reader should know or do because of it: a decision needed, a deadline, a risk.

Keep:

- numbers, dates, names and amounts, exactly as written,
- conclusions and the main reason for each,
- anything the reader must act on.

Leave out examples, repetition, background the reader already has and the author's throat-clearing.

## Stay faithful

- Report what the source says, not what you think of it. If you add a comment, label it as yours.
- Do not smooth over a caveat. "May reduce" must not become "reduces".
- When the source is unclear or contradicts itself, say so.
- For a thread or a meeting, say who holds which position.
- Never add facts that are not in the source.

## Check

Before sending, ask: could someone who reads only this make the same decision as someone who read everything? If not, the missing piece goes in.

Offer the longer or shorter version, or the list of actions, if it would help.
