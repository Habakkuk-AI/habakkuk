# Daily brief

One screen the user can read on a phone before the day starts. Lead with what needs them, not with everything that exists.

## Gather

Use only sources you can actually read. Skip a section whose source you cannot reach, and say so in one line at the end.

1. **Today**: calendar events with times in the user's time zone, and anything that needs travel or preparation.
2. **Waiting on the user**: messages and email that ask them a question or need a decision. Not newsletters, receipts or notifications.
3. **Due**: tasks, board cards and reminders due today or overdue.
4. **Since yesterday**: what you finished, what is still running, and anything that failed.
5. **Worth knowing**: only what the user has asked to be told about (weather, a price, a topic). Nothing if they have not asked.

Check your memory for what this user wants in the brief and how they like it.

## Write

- First line: the one thing that matters most today.
- Then short sections in the order above. Leave out an empty section.
- One line per item: the time or the person first, then what it is, then the action if there is one.
- Five items per section at most. Say how many more there are.
- No greeting paragraph, no sign-off, no advice nobody asked for.

## After

If the user answers with a decision ("move the 3 pm", "reply yes to Sam"), act on it or ask the one question you need.

The first time, offer to send the brief every morning at a time they choose, using a schedule if you can create one. When they say a section is not useful, save that and leave it out from then on.
